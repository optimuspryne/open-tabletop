# Reporting security vulnerabilities

Please report suspected vulnerabilities privately to
[admin@open-tabletop.com](mailto:admin@open-tabletop.com).

Include, where possible:

- The affected version or commit and deployment method.
- A description of the issue and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- Relevant sanitized logs or screenshots.

Do not send passwords, session tokens, private player data, or production database
dumps. Use test accounts and test data when demonstrating an issue.

Please avoid posting vulnerability details in public issues or pull requests
before a fix is available. Coordinate disclosure with the maintainer through the
email address above.

For ordinary bugs and feature requests, see [CONTRIBUTING.md](CONTRIBUTING.md).
