Getting started

Open Tabletop wiki

Install the app, set up a room, and learn the controls.

Choose where to start

  • Hosting a server: start with Docker Compose, or use the Node.js, Linux, Proxmox, or Portainer and Dockhand guides.
  • Joining a game: read Your first game. You need the address of your group's server and a room code.
  • Learning to play: see Mouse, keyboard, and touch, Cards, dice, and pieces, and Saving and resuming.
  • Running an existing server: see Configuration, Accounts and permissions, Backups and upgrades, and Troubleshooting.

What Open Tabletop does

Open Tabletop gives your group a shared 3D table. Players move objects, roll dice, deal cards, and manage their own game rules. The app does not enforce legal moves or calculate scores automatically.

The server runs the physics and stores shared game state. Players connect in a browser. Site administrators manage uploaded decks, boards, props, and scenes in the asset library.

Source and versions

These guides describe the repository's current source. Published releases may differ. Check the release notes and changelog for the version you install. In this checkout, account recovery, object hiding, map fog and auras, and the regular Linux installer are under Unreleased. Do not expect them in the pinned 0.20.0 image. These guides were reviewed against source on September 29, 2026.

The public demo is not available yet. To try the app, install it or join a server run by someone in your group.
